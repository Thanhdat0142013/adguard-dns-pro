# 🛡️ DNS Multi-Engine Pro (AdGuard & Cloudflare)

Bộ công cụ web giúp cấu hình nhanh DNS để chặn quảng cáo (AdGuard) hoặc tăng tốc độ truy cập Internet (Cloudflare 1.1.1.1) trên đa nền tảng.

## 🚀 Tính năng chính
- **AdGuard DNS (ID: 1c5a8e):** Chặn quảng cáo, mã độc và bảo vệ quyền riêng tư.
- **Cloudflare DNS (1.1.1.1):** Tối ưu tốc độ, giảm ping khi chơi game và lướt web.
- **Auto-Scan Windows:** Tự động cài đặt cho cả Wi-Fi và Ethernet chỉ với 1 cú click.
- **iOS Profile:** Cài đặt cấu hình DoH (DNS-over-HTTPS) chuẩn Apple.
- **DNS Checker:** Hệ thống kiểm tra trạng thái kết nối trực tiếp trên web.

---

## 🛠️ Hướng dẫn sử dụng

### 1. Windows (PC/Laptop)
- Nhấn vào nút **Windows Auto** hoặc **Windows 1.1.1.1**.
- Tải tệp `.bat` về máy.
- **Quan trọng:** Chuột phải vào file vừa tải và chọn **Run as Administrator** để script có quyền thay đổi cấu hình mạng.

### 2. iOS (iPhone/iPad)
- Nhấn vào nút **iOS Profile**.
- Chọn "Cho phép" khi hệ thống hỏi tải về hồ sơ cấu hình.
- Vào **Cài đặt** > **Đã tải về hồ sơ** > Nhấn **Cài đặt** ở góc trên cùng bên phải.

### 3. Android
- Nhấn vào nút **Android Settings**. Hệ thống sẽ tự động copy ID DNS.
- Chọn "Tên chủ lưu trữ nhà cung cấp DNS tư nhân".
- Dán mã đã copy và nhấn **Lưu**.
